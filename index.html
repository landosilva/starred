Starred
GitHub Asset Store Install

Star assets and scene objects you use often. Jump back to recent selections. See what's starred in the Project window and Hierarchy.

Favorites

A tray for the things you actually use.

Tools → Starred → Favorites

Drop in project assets or scene GameObjects. Click to select, double click to open or frame, drag out onto Inspector fields.

  • Flat ordered list. No folders, no nesting. It stays a tray.
  • Reorder by drag. Lens icon to ping in Project or Hierarchy.
  • Scene entries keyed by scene + hierarchy path. Only visible when their scene is loaded.
  • Missing or renamed objects show red so you can clean them up.

Selection History

Back to what you just had.

Tools → Starred → History

Filled automatically, newest first. Selecting an item again moves it to the top. Each row has a ★ button to promote straight to Favorites.

  • Tracks both project assets and scene / prefab stage GameObjects.
  • Single click inspects. Lens pings. Double click opens or frames.
  • Size caps configurable: 4 / 8 / 16 / 32.

Star Overlays

See what's starred without opening anything.

Favorited items get a ★ overlay in the Project and Hierarchy windows. Click the overlay to unfavorite directly. Both toggle independently in Preferences.

Context Menu

Everything a right click away.

  • Show in Project / Hierarchy
  • Show in Explorer
  • Open: scene, IDE, prefab stage…
  • Frame in Scene View
  • Copy Path / GUID / Hierarchy Path
  • Remove from Favorites

Preferences

Tune it to your workflow.

macOS: Unity → Settings → Starred  ·  Windows: Edit → Preferences → Starred

  • Show star in Project window: toggle Project ★ overlay.
  • Show star in Hierarchy: toggle Hierarchy ★ overlay.
  • Selection history max entries: 4 / 8 / 16 / 32.

Install

Get it into your project.

Requires Unity 2022.3 LTS or newer. Editor only. No runtime footprint, no dependencies.

Available on Unity Asset Store Get Starred · free Available on GitHub landosilva/starred

Package Manager

OpenUPM · recommended

Advantage: updates. OpenUPM publishes versions to a registry, so Package Manager can show new releases and version history. A git URL install stays pinned until you change the URL.

Via openupm-cli:

openupm add com.kynesis.starred

Or add the OpenUPM scoped registry, then install com.kynesis.starred from Package Manager:

Namepackage.openupm.com
URLhttps://package.openupm.com
Scopecom.kynesis

Package page: com.kynesis.starred

Git URL

Window → Package Manager → + → Add package from git URL…

Paste the URL

https://github.com/landosilva/starred.git

Pin to a release:

https://github.com/landosilva/starred.git#v0.2.0

Does not show Package Manager updates. Prefer OpenUPM if you want that.
